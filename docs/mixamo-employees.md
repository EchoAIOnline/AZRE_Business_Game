# Mixamo employee replacement

Active models: Josh (Acquisitions), Louise (Dispositions), Joe (Operations), and Suzie (Reception). Downloaded directly from the signed-in Adobe Mixamo business character collection. Original Rocketbox files remain available for rollback but are no longer selected by `employeeAssets.ts`.

All four use the same 65-joint Mixamo hierarchy and have finger joints. Bone namespaces differ (`mixamorig`, `mixamorig4`, `mixamorig7`, `mixamorig8`) and rest orientations differ slightly. The import script checks hierarchy and applies a rest-frame rotation correction to the captured animation, preserving the character's bone hierarchy, joint lengths, meshes and clothing. No new rigging is performed. Runtime semantic bone aliases support desk IK without renaming actual bones. Every clip binding and numeric track is validated before activation.

Actual Mixamo captures: Breathing Idle, Walking (Male Standard Walk), Sit To Stand, Stand To Sit, Sitting Idle (Sitting With Breathing Idle), Typing (Sitting At A Computer And Typing), and Sitting (Sitting Looking Side To Side). Exported at 30 FPS without skin. `scripts/import-mixamo-employees.py` converts the downloaded FBXs to model GLBs and animation-only GLBs. Source downloads stay outside the repository. These starter models have neutral faces; they do not provide a facial-expression or eye-animation rig.

The existing AnimationMixer, seven-state controller and department navigation remain. Captured walk root speed is measured during conversion; navigation removes world-horizontal root travel and scales clip playback to 0.65 m/s. Chair transition clips use normalized horizontal root anchors; seated and typing tracks preserve their source hip transforms. Turn rate is bounded and employees face a new path segment before stepping. Chair transitions use their authored durations, one-shot playback and fades at both ends. Foot contact IK is retained for isolated development diagnostics but disabled by default. When enabled, it locks a near-ground, low-velocity foot horizontally during locomotion and chair transitions. It releases on lift or reach limits, preserves captured foot rotation and vertical motion, and never pulls a leg beyond its reach. Root-speed calibration remains the primary walk correction.

Captured typing supplies body, arm and finger motion. Optional desk IK is available only in explicit development review layers. Mixamo's mouse search returned no suitable office clip, so the optional mouse review layer applies a small right-arm contact adjustment over captured typing. The original seated look-around capture remains imported, but its large torso lean is not used at desks; small head attention turns are available in the separate head review layer. Seated breathing supplies mild posture variation in the optional review layer. Independent schedules remain available in that layer; occasional short department walks return to the assigned chair. No CRM actions execute through these visual states.

Models use Draco-compressed geometry and WebP textures capped at 1024 pixels. The four model GLBs total about 4 MB. A single decode worker and per-URL asset/clip caches prevent repeated decoding. Preview skeletons and materials are independent; geometry and textures are shared. Materials use non-metallic skin/clothing shading. Existing office architecture, first-person controls, collision rules and avatar interactions remain.

Validation: `npm run lint`, `npm run build`, `git diff --check`, and individual tests `employeeAssets`, `employeeRig`, `mixamoEmployees`, `employeeBehavior`, `walkCollision`, `workAnimation`. Mixamo tests check all four real exported rigs, 65 joints, finger support, binding compatibility, finite sampled poses, input-clip immutability and missing-clip rejection. Browser review checks actual compressed meshes/textures and desk/preview behavior; tests alone do not establish visual quality.

## Fidelity correction and review

The previous exporter read evaluated target parent matrices while assigning and keyframing child poses. Blender's dependency graph could then combine current and stale target poses. The old typing GLBs contained adjacent-frame wrist rotations near 180 degrees, whereas the original FBX did not. Finite-value and binding checks had not detected this corruption.

The repaired exporter computes a complete desired pose from the source before writing any target transforms. It derives each local matrix basis through `Bone.convert_local_to_pose` using the computed parent pose, and maintains quaternion sign continuity. All seven captures were regenerated for all four existing characters. No skeleton, mesh, clothing, face, or joint length was replaced.

`capture-mixamo-reference.ts` independently parses the original FBX with Three.js FBXLoader and records rest-relative world rotations, hips, hierarchy and timing at 60 Hz, including half-frame interpolation. `animationFidelity.test.ts` checks all four GLBs against that compressed reference fixture. The 16.466667-second typing capture matches within 0.000018 radians in rest-relative joint motion, with hip error below 0.0000001 m. Different bind axes are explicitly accounted for; a matching 65-joint count alone is insufficient.

Typing and seated source tracks are no longer rewritten, attenuated, loop-closed, or repositioned at runtime. The default office uses the captured typing motion with procedural keyboard, mouse, posture, head and foot corrections disabled. Whole-character scale is 1.35 for workstation alignment; positions and orientation remain at the assigned workstations. Walking playback uses the corresponding scale when calibrating speed. Typing starts at independent clip offsets without altering motion or speed.

Development-only isolated review is available at `/?animation-test=typing`. It has employee and FBX/GLB selectors, pause/play and orbit controls. Each test uses one mixer and one action at 1x, with no office controller, blending, IK or secondary skeletal animation. Original FBX downloads are served by an allowlisted development-only route from `/private/tmp/azre-mixamo`; they are not copied into production assets. The source comparison requires those local downloads to remain available.

The office's development menu exposes individual opt-in review layers: breathing/review pauses, transitions, head attention, keyboard correction and mouse interaction. The default remains original capture. DOM diagnostics report finite poses and the largest observed frame-to-frame core joint rotation, along with sampled frame rate. Navigation, office geometry, avatar settings and DealDesk remain intact. Nothing is pushed or deployed as part of this review.

## Local validation after conversion repair

All ten test files, TypeScript checking, production build and whitespace checks passed. The independent 60 Hz FBX comparison covers 989 samples on each employee, including between source keyframes. Maximum rest-relative rotation error is 0.00001756 radians (about 0.001 degree); maximum hip-motion error is below 0.00000008 m. Bind axes and proportions are verified separately for each character.

Browser checks covered original playback and the breathing, transition, head, keyboard and mouse layers separately. All poses remained finite. The transition review recorded seated, standing up, outbound, standing idle, returning, aligning and sitting down for every employee. Observed core-joint frame steps remained below 0.24 radians in these optional reviews, compared with the old converted clip's near-180-degree jumps. These diagnostics are regression evidence, not a guarantee of perfect desk contact or mathematically seamless source loop endpoints. Default playback preserves the original source loop and disables all skeletal corrections.

The development transition layer schedules one staggered walk per employee for review. The isolated typing page supports source FBX and GLB playback, pause, and all four employees. It is excluded from production behavior. No publication or deployment was performed.

## Expanded library upgrade

See `animation-library-review.md` and `animation-library-inventory.json` for the 77-file audit and decisions. The default is now the curated authored workstation sequence (`animation-layer=library`), with no procedural skeletal corrections. `animation-layer=original` remains an isolated baseline option. Standing and sitting retain their existing captures; walking uses the independently validated preferred-2 capture with per-character stride calibration. Entry and exit actions finish before changes and navigation waits for a safe rest pose.

Regenerate selected animation-only assets with Blender: `blender -b --python scripts/import-mixamo-employees.py -- /private/tmp/azre-mixamo --library`. This leaves the four model GLBs untouched. The `--library` conversion selects the active 65-bone armature rather than extra FBX scene nodes. Original library downloads remain in the user's Downloads folder and are served only through an allowlisted development endpoint.

Run `node --import tsx tests/animationFidelity.test.ts --library` for independent 60 Hz source comparisons, and `node --import tsx tests/workstationPlayback.test.ts` for ten-minute full movement playback per character. The isolated animation test now includes all five candidates, original FBX/converted GLB selection and one-shot replay.
